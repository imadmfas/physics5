# الفيزياء المنبثقة — كتاب تفاعلي للصف الخامس العلمي

**افتح الكتاب:** https://imadmfas.github.io/physics5/

نسخة تفاعلية ثلاثية الأبعاد من كتاب «الفيزياء للصف الخامس العلمي»، فيها 94 صفحة مزدوجة تغطي الفصول العشرة كلها. تحتوي كل صفحة على:

- ملخص الدرس، والقانون الرئيس، وأربعة مصطلحات.
- سؤال «توقّع» يُفتح بعده شرح «لماذا؟».
- أشكال منبثقة ثلاثية الأبعاد يجرّبها الطالب بنفسه، وعرض توضيحي تلقائي بالكاميرا.
- ختم أحمر يظهر حين يجرّب الطالب كل أشكال الصفحة.

## للطلبة

يعمل الكتاب في أي متصفح حديث على الحاسوب أو الهاتف، مثل Chrome أو Edge أو Safari، ولا يحتاج إلى تسجيل أو تنصيب.

- في أسفل كل صفحة ثلاثة أزرار تجارب مرقمة (1، 2، 3)، يكفي الضغط عليها لتشغيل التجارب، ويمكن أيضاً لمس الشكل المرقّم نفسه.
- سطر الإرشاد في أعلى الشاشة يخبرك بالخطوة التالية.
- اسحب للتدوير، وقرّب بإصبعين أو بعجلة الفأرة، وانقر مرتين للعودة إلى المنظر الأصلي.
- على الهاتف: زرّا «الشرح» و«التجربة» في الأعلى، واسحب صفحة الشرح يميناً أو يساراً للانتقال بين الدروس.
- من الفهرس ☰: مستوى الصوت، والوضع الخفيف للأجهزة الضعيفة، وإعادة الجولة التعريفية.

## للأساتذة

في شريط الأدوات أسفل الشاشة زر **«أرسل ملاحظة»**. يفتح هذا الزر رسالة واتساب جاهزة فيها اسم الصفحة ورابطها، فلا يبقى عليك إلا كتابة الملاحظة وإرسالها. أرحّب بكل تصحيح علمي أو لغوي أو اقتراح.
