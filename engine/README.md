# محرك الكتاب التفاعلي المنبثق (المصدر)

هذا المجلد هو المصدر الذي بُني منه `index.html` في جذر المستودع.

- `src/lessons.js`: بيانات الدروس (المخطط: `BOOK` و`LESSONS`).
- `src/scenes.js`: المشاهد ثلاثية الأبعاد، مشهد لكل `scene.type`، ومعها الدوال المساعدة.
- `src/main.js`: المحرك (الكتاب، والصفحات، والكاميرا، والعرض التوضيحي، والقلب، والشريط، والفهرس).
- `src/template.html`: الواجهة والأنماط والغلاف وزر الملاحظات وعدّاد الزيارات.
- `build.mjs`: يجمع كل ذلك في ملف واحد `dist/index.html`.

## البناء

```bash
npm ci
WA=9647XXXXXXXXX node build.mjs   # WA: رقم واتساب الذي تصله الملاحظات
```

## الاختبار

```bash
NODE_PATH=$(npm root -g) node tests/screenshot-all.js 0,1,2
```

يفتح هذا الاختبار كل صفحة مطلوبة في متصفح آلي، ويجرّب أشكالها الثلاثة، ويحفظ لقطة لكل صفحة.
